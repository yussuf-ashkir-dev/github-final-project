# Simple Interest Calculator

## Project Description

A simple interest calculator built using Bash scripting. It calculates simple interest based on the principal amount, annual rate of interest, and time period in years.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

- **Principal:** The initial amount of money.
- **Rate:** The annual interest rate, expressed as a percentage.
- **Time:** The duration in years.

## Output

The calculated simple interest amount.

## Usage

Run the calculator using:

```bash
bash simple-interest.sh
```
